# Data Privacy And Governance Test Specification

**Date:** 2026-05-18
**Status:** Current planning baseline

## Required Tests

- Customer deletion preserves invoices and audit records.
- Anonymization masks direct identifiers.
- Export excludes unauthorized branch data.
- Restricted note access requires reason and writes audit.
- Customer merge is blocked across businesses.
- Privacy request execution is idempotent.
- Export download link expires.
