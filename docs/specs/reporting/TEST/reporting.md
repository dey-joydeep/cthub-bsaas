# Reporting And Analytics Test Specification

**Date:** 2026-05-18
**Status:** Current planning baseline

## Required Tests

- Financial report reconciles finalized invoices and payments.
- Refunds and dues are separated.
- Branch scope filters exclude unauthorized data.
- Staff report uses transaction-time commission snapshot.
- Export creation writes audit record.
- Large export returns async status.
- Deactivated staff/customer displays safe historical name.
