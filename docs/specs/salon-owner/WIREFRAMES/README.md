## Penpot Board Naming Standard

Use these board names when creating or regenerating Penpot frames:

- `<feature>.<screen-state>.desktop`
- `<feature>.<screen-state>.tablet`
- `<feature>.<screen-state>.mobile`

Desktop frames are required for MVP operational screens. Tablet and mobile frames are added when the screen is part of MVP responsive delivery.
